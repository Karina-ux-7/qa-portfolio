# Projeto 01 — Testes Manuais

Este projeto tem como objetivo praticar e demonstrar atividades de Quality Assurance com foco em testes manuais de uma aplicação web.

## Objetivo do projeto

Aplicar técnicas de testes de software em uma aplicação real ou de demonstração, documentando o processo de análise, execução e identificação de defeitos.

## Tipos de teste que serão aplicados

- Testes funcionais
- Testes positivos
- Testes negativos
- Testes exploratórios
- Testes de regressão
- Validação de regras de negócio

## Atividades do projeto

Durante este projeto serão realizadas as seguintes atividades:

- Análise da aplicação
- Identificação dos principais fluxos
- Criação de cenários de teste
- Criação de casos de teste
- Execução dos testes
- Registro de resultados
- Identificação de defeitos
- Documentação de bugs
- Registro de evidências

## Estrutura do projeto

Este projeto será organizado com:

- `casos-de-teste.md` — documentação dos casos de teste
- `bugs.md` — registro dos bugs encontrados
- `evidencias/` — imagens e evidências das execuções

## Status

Em desenvolvimento.

O projeto será atualizado conforme os testes forem sendo executados e documentados.
