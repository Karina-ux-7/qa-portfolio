# Projeto 02 - Testes de API com Postman

Projeto prático de testes de API realizado com Postman utilizando a API pública Restful Booker.

## Objetivo

Praticar a validação de endpoints, métodos HTTP, respostas da API, autenticação e manipulação de dados em formato JSON.

## Cenários realizados

- listar reservas com GET
- criar uma reserva com POST
- consultar uma reserva específica por ID
- atualizar uma reserva com PUT
- validar autenticação
- analisar respostas 200 OK, 403 Forbidden e 404 Not Found

## Conceitos praticados

- API REST
- endpoints
- métodos HTTP
- GET
- POST
- PUT
- JSON
- status code
- autenticação
- token
- Basic Auth
- análise de response

## Ferramenta utilizada

Postman
